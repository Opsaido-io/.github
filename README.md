# opsaido-io/.github

The organisation's defaults, shown on every Opsaido repository that doesn't have its own:

- `profile/README.md`: the page at github.com/opsaido-io
- `SECURITY.md`, `SUPPORT.md`: how to report a vulnerability and where to get help
- `ISSUE_TEMPLATE/`: the bug report and feature request forms
- `PULL_REQUEST_TEMPLATE.md`: the pull request checklist

Edit them here once and every repository follows.
