# Security policy

We take the security of Opsaido seriously, because it manages other people's servers.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Email **hello@opsaido.io** with the subject "Security", and include:

- what you found and where (the page, the endpoint or the file),
- the steps to reproduce it, and the version you tested (Settings → About shows it),
- what an attacker could do with it.

You'll get an acknowledgement within **3 working days**, and we'll keep you informed until it is fixed. Please give us reasonable time to release a fix before you share details publicly. We're happy to credit you in the release notes if you wish.

## What is in scope

The Opsaido application and its licence server, and the website at opsaido.io. Out of scope: findings that need a compromised administrator account, denial of service by sheer volume, and issues in third-party systems Opsaido connects to.

## Supported versions

Security fixes go into the latest release. We recommend keeping your installation up to date; the app tells you when a new version is available.

## How Opsaido protects your systems

See [the security model](https://opsaido.io/docs/security-model): approvals for every change, credentials kept encrypted on your own server and never shown to the assistant, and a full audit trail.
