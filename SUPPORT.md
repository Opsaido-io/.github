# Getting help

- **Documentation:** [opsaido.io/docs](https://opsaido.io/docs) covers installing, connecting your systems, permissions, approvals and security.
- **Ask the app:** Opsaido's own assistant can answer how-to questions about itself.
- **What's new:** [the changelog](https://opsaido.io/changelog) lists every release.
- **Something not working?** Open an issue in the repository with the steps to reproduce, the version (Settings → About) and, if you can, the support bundle from Settings → Logs (the log, system facts, connector names and results, open alerts and recent audit events; look it over before you attach it).
- **Questions about plans or licences:** [sales@opsaido.io](mailto:sales@opsaido.io) or see [pricing](https://opsaido.io/pricing.html).
- **Anything else:** [hello@opsaido.io](mailto:hello@opsaido.io).

For a security problem, please follow the [security policy](SECURITY.md) instead of opening an issue.
